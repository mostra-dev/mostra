# mostra-host

The Rust host crate (HO-03, D59, D143): Rust hosts integrate with Mostra through it without
touching Mostra. Audience: Rust hosts. Depends on serde, tokio and the HTTP stack for bundle
downloads; never on anything of Mostra but the published protocol schema (tools/package-map.ts,
REPO_STANDARDS §3).

## Invariants it owns

- **The wire types are the schema's.** `src/wire/generated.rs` and `src/wire/methods.rs` are
  generated by `crates/mostra-host-codegen` from `packages/protocol/schemas/protocol.draft-07.json`
  and committed; its snapshot test fails when they are stale. Never edit them by hand: change the
  Zod schema, run `pnpm --filter @mostra/protocol gen:schemas`, then
  `cargo run -p mostra-host-codegen -- write`.
- **Newer instances never break this crate (HO-07, D143 item 3).** Every generated enum has an
  `Unknown` variant that keeps and re-serializes a value it doesn't know; unknown fields are
  ignored. The generator refuses a schema outside the subset typify handles.
- **Nothing runs from a bundle that hasn't been checked (D142).** `src/bundle.rs` checks an
  archive's size and SHA-256 against the pins before opening it, extracts only files, directories
  and links under the archive's top directory, checks every file and link against `files.json`
  before the rename into the cache, and only then runs the bundle's own `bin/mostra-setup`.
- **Port handlers can't stall or crash the session.** Each port call runs in its own task; a
  handler's error or panic answers the instance at once with `MOSTRA_HOST_INTERNAL_ERROR`.
- **No telemetry (D119, D140 item 1).** Nothing in this crate can send an event.

## Public interface

`src/lib.rs`: `Mostra`, `Options`, `ports`, `wire`, `events`, `runtime`, `bundle`, `Error`.

## Tests to run

- `cargo test -p mostra-host`: the wire types against additive change, the bundle manager
  against synthetic bundles, and (with `packages/runtime/dist` built) real instances: spawn,
  attach, typed calls, a named event stream, a port answered on the connection.
- `pnpm check --job rust` builds the runtime first and runs all of it with cargo-deny.
- The conformance kit runs the Rust reference host (`crates/mostra-reference-host`) through every
  scenario (`pnpm check --job conformance`).

## Gotchas

- `ports::Addressing` (HO-10) answers `port/addressing.externalBase`: the external origin a host
  forwards to the loopback `local` it is told, or `None`. A host that answers the same origin
  keeps its links working; `None` or another origin withdraws the one before.
- The protocol's ID types are validated newtypes; build params with `serde_json::from_value` or
  the helpers on `Mostra`, which take `&str` IDs and paths.
- `Options::new` copies this process's environment; `Options::env` replaces it. Proxies, the
  cache and `MOSTRA_BUNDLE*` are read from that environment, never silently from the process.
