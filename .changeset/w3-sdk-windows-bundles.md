Windows hosts run on Mostra's Windows bundles: the platform gate takes win32 x64 and arm64, the bundle cache is `%LOCALAPPDATA%\mostra-cache`, a Windows archive's links (which it never carries) are made as junctions at setup, so an ordinary user installs one, a moved Windows bundle is set up again, and a rename an antivirus scan holds for a moment is tried again. The instance a host spawns opens no console window.
