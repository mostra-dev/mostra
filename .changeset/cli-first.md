The first release of `mostra`, the CLI (D60, D140): every WP-10 command, `mostra dev` included, as a thin client of the host protocol with daemon autostart, `--json` envelopes, one exit-code table, generated help and `--help --json`, `mostra docs`, `doctor`, `gc`, and anonymous telemetry for the standalone CLI only, which this build never sends (it has no endpoint).
