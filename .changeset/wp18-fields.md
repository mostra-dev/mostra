A field may name its options (`useField(id, initial, { options: [{ value, label, recommended }] })`), and results name each answer by the label the viewer saw and say whether they took the recommended one (WP-18). The shell tells a page the person's light or dark, and a host's look (`HomeConfig.look`) reaches only a page whose stack names `"host"`, in the shell and inline in an MCP Apps host alike; the MCP App exporter keeps the page's theme.
