Hosted pages show one link preview for every artifact ("A page sent with Mostra", `noindex`), or the title alone when the manifest sets `hosted.preview: "title"` (D161). The remote server accepts up to 1 MiB of request headers, so a sibling page filling the cookie jar never costs a hosted page its session, and a hosted frame's documents name the same framers as its refusals, an operator's outside hosts included.
