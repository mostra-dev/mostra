# @mostra/warm

The warm set of [Mostra](https://github.com/mostra-dev/mostra): the packages every artifact can
import with no `package.json` and no install, such as React, React Router, Tailwind CSS and
`@mostra/react`. It holds no code. The Mostra runtime links each build to it, and the runtime bundle
ships it. It isn't published to npm. Apache-2.0.
