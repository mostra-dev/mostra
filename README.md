# Mostra

**Mostra is the agent artifact runtime.** Agents write ordinary React. Mostra turns it into stateful, interactive web artifacts: questionnaires, design reviews, dashboards, decks, terminal and web demos, pages with buttons that do real things. People view them, answer, comment and choose, and the answers flow back to the agent through whatever host it runs in.

## Status

The v1 design is accepted, and implementation is starting. There is no installable release yet.

- [docs/design/](docs/design/README.md) is the design: decisions, architecture, interfaces, data model, failure behavior, requirements and the work-package plan.
- [docs/research/](docs/research/INDEX.md) holds the research reports behind it.
