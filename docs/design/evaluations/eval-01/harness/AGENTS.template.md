# Project notes

- Vite + React 19 + TypeScript + Tailwind CSS 4.
- shadcn/ui components are installed in `src/components/ui`. Use them. Don't edit files in that folder.
- The page is `src/App.tsx`, which `src/main.tsx` imports as the default export. You may add files under `src/`.
- Path alias: `@/` maps to `src/`.
