# MOSTRA_REVIEW_TOO_MANY

Too many threads or comments. Severity: error. Phase: host.

## What it means

A viewer keeps at most 1,000 threads on one artifact, and a thread holds at most 500 comments.

## How to fix it

Reply in an existing thread.

## Hint

Resolve or reply in the existing threads instead of starting new ones.
