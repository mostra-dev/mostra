Every file is written aside first now, and what a change replaced or deleted is put back when a later step fails (`commit.test.ts`, with a rename that fails as a full disk does).
- **Claude Opus 5.5** (D144), run by Mirza on 2026-11-03 against `f70d096`, posted on #120 (Anthropic, run and approved by Mirza, D34): the package's only D80 review. Ten findings (two P2, eight P3), all valid, each fixed with a check red on the old code and a seed (`0bc9eb3`):
  1. (P2) Calls that met a daemon restart together each cleared the session and opened another, so all but the last stayed attached to the daemon and kept it from its idle exit. A call drops only the session it used (`test/unit/mcp.test.ts`, three calls on a stand-in daemon).
  2. (P2) `mcp.session` came only from a tool call or resource read, so a 2025-era client over HTTP (a fresh server per request, `initialize` on its own) and a client that only lists tools were never counted. The server reads the client once its handshake is done and when each instance closes (`server.test.ts` on both eras, and `mcp.test.ts` with Codex's own client name over the real HTTP listener).
  3. (P3) A write made folders before every path was checked, and a failed change left them. Every path and folder is checked first, a name can't be both a file and a folder, and the folders a failed change made (the artifact's directory included) are removed.
  4. (P3) `MOSTRA_ARTIFACT_ID_DROPPED` missed `Index.tsx` on a folding file system, a deleted entry and a swapped one, and the duplicate check was case-sensitive. The warning judges the whole change, entries matched without regard to case, and two names that differ only in case are one file in a change.
  5. (P3) Names Windows reads otherwise (`index.tsx:x`, a trailing dot or space, `CON`, `nul.tsx`) were accepted. The tools take only names every system can hold, so an artifact moves between systems whole.
  6. (P3) A plain diff's `a/index.tsx` was read as the root's file, and a diff's rename replaced a file that was there. `a/` and `b/` are dropped only in git's form; a rename onto a file is `exists`.
  7. (P3) A folder swapped for a link between the path check and the write took the write out of the artifact. Each step acts only while the file's folder is still inside it (`commit.test.ts`, with the swap made just before a write).
  8. (P3) `--json` put a generated token on stdout, against D164 item 3. It goes to stderr only; `listening` carries the URL.
  9. (P3) Nothing tied the schemas `tools/list` serves to the bundle the D32 snapshot holds. A test holds them equal on both eras.
  10. (P3) `bearer` in lower case was refused and counted as a guess, and `MOSTRA_MCP_TOKEN=aaaa…` was accepted. The scheme is read without regard to case, only a wrong bearer token counts, and a chosen token needs eight different characters.
