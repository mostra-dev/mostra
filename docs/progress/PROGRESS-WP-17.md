## Deviations

- **`artifact_open` names a loader, not each version's page.** INTERFACES §12 had `artifact_open` return `ui://mostra/view/<versionId>`; MCP Apps names a tool's UI on its definition, so it names the static `ui://mostra/app`, which reads the version's page (D175 item 1). The versioned resource stays, for a host that reads it itself.
- **A hosted home makes its own pages.** As first built, the owner sent each version's page after its push (`hosted/page`); after Opus 2 the hosted home makes it from the version's own client files, and `hosted/page` and the relayed `app/page` were removed before release, so no published interface changed (D175 item 8).
- **WP-34's planned migration is 19.** ORGANIZATION-HOMES and WP-34's specification had planned the owner ledger's migration 18; WP-17 took 18 first, so the plan says 19 (a number only; nothing of WP-34 is built).
- **Size budgets** raised for the new chunk of `@mostra/react` and the protocol's methods (D175 item 11).
